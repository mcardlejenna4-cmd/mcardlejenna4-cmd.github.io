# Jenna McArdle – Portfolio

My personal portfolio website. I'm a first-year Immersive Software Engineering student at the University of Limerick, and I'm looking for a software engineering work placement starting June 2027.

**Live site:** [mcardlejenna4-cmd.github.io](https://mcardlejenna4-cmd.github.io)

## About the site

The site is written in plain HTML and CSS, with no frameworks or build tools, and is hosted on GitHub Pages. It includes:

- **About me:** who I am as an engineer and what I want from a placement
- **Skills:** languages, tools and professional skills
- **Projects:** things I've built, with links to the code
- **Experience:** jobs, clubs and extra-curriculars
- **Industry engagement:** talks and online courses
- **Goals:** what I want to achieve on placement
- **CV:** an online HTML version of my CV, with an option to download it as a PDF

## Accessibility and performance

Accessibility matters to me, so I tested the site with two tools:

- **Lighthouse score: 98**
- **WAVE: no warnings or alerts**

Accessibility features include:

- An HTML version of the CV, so visitors don't have to open a PDF. The PDF is still available, and its links say clearly that they open a PDF file.
- Text colours chosen to pass contrast checks
- Proper heading structure, so screen readers can jump between sections
- A "Skip to CV" link and visible focus outlines for keyboard users
- A responsive layout that works on phones
- A print style on the CV page, so only the CV is printed

## Running it locally

There's nothing to install. Clone the repo and open `index.html` in a browser:

```bash
git clone https://github.com/mcardlejenna4-cmd/mcardlejenna4-cmd.github.io.git
cd mcardlejenna4-cmd.github.io
```

## Updating the CV

The CV exists in two places: `cv.html` and `cv.pdf`. When one is changed, the other must be updated to match.
