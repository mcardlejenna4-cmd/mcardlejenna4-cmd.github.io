01 / About me

Who I am as an engineer

My interest in software came later than it did for many of my classmates. I’ve always been the one who’s “good with technology”, but my interest in building things only started in my late teens, when friends showed me how accessible software engineering really is. Little by little, I discovered tools like GitHub and VS Code, and learning platforms like W3Schools and boot.dev, and I realised that software isn’t reserved for a select few. Anyone can create with technology. In fact, I think it’s one of the greatest outlets for creativity today. I chose an immersive programme because I believe in learning by doing. The fastest way to learn French is to go to France, so why should software be any different? I’d rather be thrown into the world of software engineering head first and learn along the way.

I work meticulously: I like structured plans, clean code and consistency across a codebase. I enjoy working in teams and I’m a strong communicator, partly because I’m never afraid to ask questions. I care about user experience and want to make technology as seamless as possible, so that people of all abilities can use it.

I haven’t chosen a specialism yet, and right now that’s a strength. I want to try everything: websites, games, financial tools, cybersecurity and more. So far, I’m especially drawn to fintech and microelectronics, but I won’t know where my passion truly lies until I’ve tried things in a real setting. That’s what I want from my first placement: a genuine taste of professional software engineering, and the chance to discover where I can contribute most.
